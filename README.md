# Muslim Website - Prayer Times, Qibla Direction, and Daily Azkar

## Overview:
A comprehensive web application designed to assist Muslims in their daily life by providing:
- Accurate prayer times.
- Qibla direction.
- Daily Azkar (remembrances).
- Modern design and seamless user experience.

## Features:
- **Qibla Direction**: Manually set using the coordinates of the Kaaba for accuracy.
- **Prayer Times**: Based on the user's geographic location, with time remaining for the next prayer.
- **Smart Notifications**: Alerts for city change or upcoming prayer times.
- **Smart Compass**: Qibla direction using Geolocation API.
- **Daily Azkar**: Morning and evening remembrances, with easy copy feature.
- **Responsive Design**: Smooth experience across all devices.

## Technologies Used:
- **Frontend**: React.js, Tailwind CSS, Framer Motion
- **APIs**: Geolocation API for Qibla direction
- **Libraries**: React Notification for smart alerts

## Why is this project useful?
- Combines three essential services for Muslims into one platform.
- Provides high accuracy in prayer times and Qibla direction.
- Features a responsive, easy-to-use design across all devices.
- Built with modern technologies to ensure quick performance and a seamless experience.
